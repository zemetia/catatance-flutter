# Pencatatan Keuangan

Personal finance tracking app — Flutter, local-first (Android + iOS).

> **Start here:** [CLAUDE.md](CLAUDE.md) — points to the full blueprint (`docs/blueprint/`) and the project knowledge system (`docs/knowledge/`).

## Stack

Flutter · Dart 3 · Riverpod · go_router · Drift (SQLite) · freezed · flex_color_scheme · google_fonts · flutter_animate · fl_chart

## Getting started

```bash
flutter pub get
dart run build_runner build --delete-conflicting-outputs
flutter run
```
